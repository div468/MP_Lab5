# MP_Lab5

Aplicación de ejemplo que utiliza la **PokeAPI** para crear una lista de Pokémon.  

---

## 📋 Descripción

Este proyecto es una pequeña aplicación en **Kotlin** que consume la PokeAPI para mostrar una colección de Pokémon con sus distintas imágenes características. Desarrollo con el fin de practicar la integración de APIs REST y manejo de datos.

---

## 🧰 Tecnologías y herramientas

- Kotlin  
- Jetpack Compose
- Viewmodel para separación de datos y lógica de la aplicación
- Librería de red Retrofit  
- PokeAPI
- Gradle

---

## 🚀 Cómo ejecutar el proyecto

1. Clona el repositorio:

   ```bash
   git clone https://github.com/div468/MP_Lab5.git

2. Abrir el proyecto en Android Studio

3. Sincronizar los archivos Gradle para descargar las dependencias utilizadas

4. Iniciar un emulador 

5. Ejecutar la aplicación

## ✅ Funcionalidades
1. Uso de datos de la PokeAPI
2. Desplegar la lista de Pokémon recibida por la PokeAPI
3. Mostrar cuatro imágenes de cada pokemon en una pantalla de detalles
4. Manejo de estados de carga
